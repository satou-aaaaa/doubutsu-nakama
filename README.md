# 動物なかま分け（doubutsu-nakama）

動物の名前とくらしの様子を見て、脊椎動物の5つのなかま（魚類・両生類・は虫類・鳥類・哺乳類）のどれかを当てる1日5問の学習ゲーム。正解したら「呼吸のしかたは？」（えら・子はえらで親は肺と皮膚・肺）も選ぶ。イルカ・ペンギン・イモリ・ウミガメなど、まちがえやすい動物も出る。

遊ぶ: <https://satou-aaaaa.github.io/doubutsu-nakama/>

- 中身は大阪府教育委員会「中学2年理科 16 動物のなかま」のプリント（解答）と、東京ズーネット（どうぶつ図鑑）・海遊館（生き物図鑑）の分類で確かめたことだけです。
- くわしくは教科書や、動物園・水族館の図鑑で確かめてください。
